Before creating clips, state a compact direction: audience and message, a visual reference in words, hero element, type roles, palette roles, alignment system and the intended viewing size. Tie the decisions to this brief. A template aesthetic is not a substitute for a direction.

Inspect actual owned assets and their dimensions. Clipzu MCP can place and transform uploaded images/videos; it cannot choose a font, write native text, draw a shape, recolor artwork or generate a mask. Plan typography and geometry within authorized source artwork, or explain which sources are missing. Split a title into separate word images only when those assets actually exist. Preserve brand requirements and source licenses.

Choose one primary reading target per scene. Arrange supporting information so it is encountered after that target; use scale, spacing and contrast before adding decoration. Align related objects to a small number of guides and allow room for the hero's full motion envelope. Check margins at the delivery aspect ratio, including intended captions/platform overlays.

Read [art-direction.md](references/art-direction.md) for a practical direction sheet and review process. Evaluate the real preview at the delivery size, including intermediate motion frames. If no preview access is available, label layout judgments provisional rather than describing an unseen frame as polished.

Hand off clear visual priorities to **clipzu-motion**: what enters first, what must remain readable, and what can move in support. Keep design decisions separate from claims about unsupported native text, 3D, blur or effects.
